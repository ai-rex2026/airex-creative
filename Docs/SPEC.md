# AI-REX クリエイティブ／運用フェーズ 設計仕様書 v0.2（9月リリース版）

> 位置づけ：既存の AI-REX（URLを入れると広告戦略レポートが出る「診断」）の**続き**をつくる。
> 診断で終わらせず、クリエイティブ制作 → 配信 → 改善までを自動で回す。
> 2026-09-05 の打ち合わせ（渚／田代）を起点に作成。**未確認事項は「◻要確認」と明記**。

## 1. 競合（ここが仕様の出発点）

| | 極予測AI シリーズ（サイバーエージェント） | Meteo（マイルストーン） | AI-REX（自社） |
|---|---|---|---|
| 中核 | **配信前に効果を予測**するAI。予測値が既存を上回ったものだけ出す | **Meta広告の自律運用エージェント**。構築→ターゲティング→制作→入稿→レポート→改善を一気通貫 | **URL入力だけの無料診断**（7章の広告戦略レポート／約8〜10分） |
| 対象 | バナー（極予測AI）／検索TD（極予測TD）／LP（極予測LP） | Meta広告 | 全媒体の戦略レポート（現状は分析のみ） |
| 料金 | 広告効果が出た時のみの成果報酬型（LPは運用額の概ね5〜10%との解説あり） | 初期10万円＋月額 **広告費の5%**（最低5万円／10アカウントまで／契約縛りなし） | ◻未定 |
| 状況 | 2020年〜。コピー自動生成(2023)・商品画像自動生成(2024)まで拡張 | 2026-06-01 提供開始、2ヶ月で**100社超**・問い合わせ約800件 | LPは実質空（JS描画のみでOGP/本文なし） |

**読み取れること**
1. 「5%」は Meteo の実勢価格。**同じ5%で並べても勝てない**ので、価格ではなく入口（診断）と対応媒体で差をつける。
2. Meteo は Meta 一本。**リスティング＋Meta の両輪**を1つの診断結果から回せるなら、そこが空き地。
3. 極予測は「予測モデル」が資産。データ量で正面から戦うのは不利。**診断→制作→配信の速さ**で戦う。

### 自社の差別化（仮説・◻要確認）
- **入口が無料診断**：登録もクレカも要らない診断でリードを取り、そのレポートをそのままクリエイティブの入力にする。競合は「契約してから」始まる。
- **診断結果とクリエイティブが同じ根拠で繋がる**：「レポート3章で指摘した競合の訴求に、この10本で当てる」と説明できる。
- **表現チェックを標準装備**：景表法・薬機法のNG表現を生成時に弾く（歯科・医療・美容を扱う前提なら必須）。

## 2. ユーザーペルソナ（◻未承認：渚さんの確認待ち）

**P1 代理店を切りたい中小事業者**（月額広告費30〜300万／社内に兼務の担当1名）
- 課題：クリエイティブが作れず出稿が止まる。代理店手数料20%が重い。何に効いているか分からない。
- 期待：バナーとLPが勝手に出てきて、成果の悪いものが勝手に止まる。

**P2 多店舗チェーンのマーケ責任者**（例：歯科クリニック10店舗、1店舗あたり広告費500万〜5,000万）
- 課題：店舗ごとにLP・バナーを出し分けたいが制作が追いつかない。店舗間で成果差の理由が説明できない。
- 期待：店舗別に量産・自動出し分け。全店を1画面で比較。

**P3 AI OSI URI 自身（ドッグフーディング）**
- 課題：AI-REX の LP が弱く、自社の獲得が回っていない。売る側なのに実績がない。
- 期待：自社LPをこの仕組みで回して、**その数字自体を営業資材にする**。

## 3. ユースケース（状況 → 操作 → 得られるもの）

1. **診断から制作へ**：広告が伸び悩む → AI-REX にURLを入れて診断 → レポートの訴求軸ごとにバナー案が10本出てくる。
2. **量産と出し分け（P2）**：新メニューを10店舗で告知したい → 店舗リストと商材を入れる → 店舗名・エリア・価格だけ差し替えた10セットが出る。
3. **回して直す**：配信して3日経つ → 成果データを取り込む → 下位のクリエイティブを止め、勝ちパターンから派生案を再生成する。
4. **自社で回す（P3）**：AI-REX のLPを作り直す → 自社アカウントで配信 → CPA推移をそのまま営業資料に載せる。

## 5. 技術方針（重要な決定）

**日本語バナーの文字を画像生成モデルに描かせない。**
- 拡散モデルは日本語の字形が崩れ、広告として出せる品質にならない。文字サイズ・行間・ロゴ位置の再現性もない
- したがって **レイアウトは DOM（HTML/CSS）で組み、ブラウザ側で PNG 化**する。生成AIに任せるのは
  「コピー」と「文字が入らない素材（背景・キャラ）」だけ
- 効果：同一デザインで文言だけ差し替えた量産が確実にできる。テンプレが資産になる

**v0 はデータベースを持たない。** 診断結果と生成物はブラウザに保持し、成果物はダウンロードで渡す。
案件管理・履歴・チーム共有が要るようになった時点で永続化層を足す（それまでは作らない）。

**媒体ごとの縦横比は余白の機械的な分配で吸収する。** 絶対配置だと 1080×1920 で間延びし 300×250 で溢れる。
縦フレックス（ヘッダ／本文／フッタ）＋「枠に収まる字送りからの見出しサイズ逆算」で6サイズを1コンポーネントで賄う。

## 7. LP戦略（AI-REX 自社LPの作り直し）

現状の `lp.airex-ad.ai` は JS 描画のみで本文・OGPが取れず、広告のリンク先としても検索面でも弱い。

- **ファーストビュー**：「URLを入れるだけでいい。」／登録不要・クレカ不要 → 診断フォームを即出す
- **中盤**：診断レポートの実物（7章）を見せる。何が分かるかを具体で
- **後半**：診断で終わらせない＝制作・配信・改善まで。自社実績（P3のドッグフーディング数値）を置く
- **CTA**：「無料で診断する」1本に絞る。資料請求は従に
