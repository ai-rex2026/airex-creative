# AI-REX デザイン仕様

本番の [airex-ad.ai/ja](https://airex-ad.ai/ja) と [/ja/about](https://airex-ad.ai/ja/about) を
ブラウザで実際に触り、`getComputedStyle` で取った実測値。**推測ではなく現物の値**。

作るもの（LP・Studio・バナー・レポート）はすべてこの仕様に合わせる。

---

## 1. 第一印象

**明るい生成り × 黒 × 落ち着いた金。** 派手さで押さず、余白で品を出す作り。

- 背景は白ではなく**わずかに温かい生成り**（#FAFAF7）。真っ白は使わない面が多い
- 金は蛍光的な黄色ではなく**アンティークゴールド**（#C9A84C）。彩度を上げない
- 影はほぼ使わない。面の区切りは**1px の罫線**（#E5E2DC）と背景色の差で作る
- 中央揃えの見出し ＋ 大きな余白。要素を詰め込まない

> ここを外すと別物になる：**背景を白にしない／金を明るくしない／影を足さない。**

## 2. 配色トークン

| 用途 | 値 |
|---|---|
| 背景（基調） | `#FAFAF7` |
| 背景（白い面） | `#FFFFFF` |
| 背景（一段沈めた面） | `#F4F3F0` |
| 背景（ダークセクション） | `#1F1E1B` |
| ボタン・濃い面 | `#2E2D29` |
| 見出しの文字 | `#1F1E1C` |
| 本文の文字 | `#1A1A1A` |
| 罫線 | `#E5E2DC` |
| 金（面・グラデーション） | `linear-gradient(135deg, #C9A84C 0%, #E8C97A 60%, #C9A84C 100%)` |
| 金（文字・アイコン） | `#9A7A2A` |

ヒーローの背景だけ淡いグラデーション：
`linear-gradient(in oklab, #FAF9F7 0%, #FFFFFF 50%, #F4F2EE 100%)`

## 3. タイポグラフィ

| | フォント | 使い方 |
|---|---|---|
| 見出し | `Poppins, "Noto Sans JP", sans-serif` / **700** | h1・h2・カード見出し・数値 |
| 本文 | `"Open Sans", "Noto Sans JP", sans-serif` / 400 | 説明文・ラベル・ボタン |

実測値：

| 要素 | サイズ | 字送り | 行間 |
|---|---|---|---|
| h1 | 36px / 700 | −0.9px | 45px（1.25） |
| h2 | 30px / 700 | 標準 | — |
| 見出しの上の小ラベル（eyebrow） | 14px / 600・**金 #9A7A2A** | **+1.4px** | — |
| 本文 | 16px / 400 | 標準 | — |
| 補足・注記 | 14px / 400・グレー | — | — |

**h1 は2行構成。1行目が黒、2行目が金**（`background-clip: text` でグラデーションを流す）。
これがブランドの顔なので、見出しは必ずこの形にする。

## 4. 形

- 角丸は **12px が主**（実測で49箇所）。入力欄・小さいチップは 10px、大きいカードは 16〜24px
- ボタンとタグは**完全な丸（ピル）**
- 影はほぼ無し。使うとしても `0 1px 3px rgba(0,0,0,.1)` 程度まで
- 区切りは 1px `#E5E2DC`

## 5. 部品

**eyebrow → h2 → 補足文 → 本体**
セクションはこの順で始まる。eyebrow は金・小さめ・字送り広め。h2 は中央揃え。

**ダークヘッダー付きカード**
上部に `#2E2D29` の帯（ドメイン名＋タイトル＋ステータスバッジ）、下に白い本文。角丸16px。

**スタットの並び**
3〜4分割し、縦罫線で区切る。上に大きい数値（Poppins 700）、下に小さいラベル2行（用途・注釈）。

**ランキングカード**
左に**濃い四角の番号バッジ**、中央にタイトル、右に金額。下に4つのスタットチップ（`#F7F6F3`・角丸10px）。
カード上端に順位に応じた色の細い帯（1〜2位は濃い色、3位以降はグレー）。

**進捗バー**
細い角丸バー。金の濃淡で3段階（`#8A7434` / `#C9A84C` / `#DCCB9A`）。右端に％。

**3ステップ**
`#2E2D29` の丸に白い番号、右に太い見出しとグレーの説明。左揃えで縦に並べる。

**機能チップ（ダークセクション）**
`#1F1E1B` の面に、少し明るい枠のカード。左に金の細いアイコン、右にラベル。角丸12px。
強調したい1つだけ金の色味を敷く。

**注記**
数値を出したら ⓘ 付きの注記を必ず添える。本番でもこう書いている：
> 表示回数・クリック・CV数・CTRは業界平均をもとにした目安です。実績を保証するものではありません。

**この一文はAI-REXのトーンそのもの**なので、こちらが作る画面でも同じ姿勢で書く
（勝ち筋スコアの注記もこの形に揃える）。

## 6. 言い回し

- 「URLひとつで、」「たった3ステップ」「わずか5分」— **数を出して短く言い切る**
- チェックの並びで安心材料を3つ：`✓ 登録不要　✓ クレジットカード不要　✓ すぐに分析を開始`
- ボタンは「無料で始める」「無料でアカウント作成」＋ **右向き矢印**
- 煽らない。限定・カウントダウン・赤い警告色は使っていない

## 7. 実装メモ

- フォントは Google Fonts の Poppins / Open Sans ＋ Noto Sans JP
- CSS 変数は本番ではほぼ使われていない（レスポンシブの文字サイズ 6つだけ）。
  こちらは `:root` にトークンを定義して使う（保守のため。見た目は変えない）
