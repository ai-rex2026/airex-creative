IBクリニック個社向けの分岐は入れていない。

```
鈴木さん

いただいた7点、すべて直して本番に上げました。
https://airex-studio.vercel.app

個社向けの調整ではなく、どのサイトでも同じように動く形にしています。

▼ 入力タブ

1 公式SNSを実際に見に行くようにしました
検出で止めず、アカウントのページを開いて
フォロワー数・投稿数・プロフィール文を読みます。
読めた数値は分析データタブと施策の生成の両方に反映します。

ただし媒体によって取れるものが違います。
IBクリニックさんのサイトで試したところ、
LINEはページを読めましたがフォロワー数は非公開、
Instagramはログインを求められて読み取れませんでした。
読めなかった媒体は理由をそのまま画面に出し、
数字は推測で埋めていません。

すでに運用しているSNSを「新しく開設する」施策としては
出さないようにもなりました。

▼ 施策タブ

2 施策が更新されないことがある件
「施策を作り直す」を単独のボタンにしました。
KPIを足したときだけでなく、いつでも押し直せます。
作り直しは1〜2分かかるので、進行中であることを画面に出します。

選んだKPIに効く施策が1件も無い状態は、
作り直しが途中で終わった状態です。
その場に警告と再実行ボタンを出すようにしました。

原因も直しています。この画面から呼ぶ処理はAIを2回叩くため、
既定の実行時間では途中で切られていました。時間を確保しました。
保存に失敗しても画面上は成功に見えていた箇所も直しました。

▼ 分析データタブ

3 見出しへのリンク
目次を付けました。章は条件によって出たり消えたりするので、
一覧は実際に出ている見出しから作っています。
いま読んでいる章が目次側で光ります。

4 複数の価格があるときの主力商材
初期値はこれまでどおり自動で選び、
横に「変える」ボタンを付けました。
掲載価格から選び直せます。サイトに無い価格は手入力もできます。
選び直すと損益分岐CPAを計算し直します。

5 Meta広告の件数・文字数
媒体ごとの辞書に切り出しました。

　Meta：見出し5件・27文字／メインテキスト5件・125文字
　Google検索：見出し12件・全角15文字／説明文4件・全角45文字

数え方も分けています。Google・Yahoo!は全角を2として数え、
Meta・LINE・TikTokは文字数そのままです。
文字数超過の検出も、書き直しも、画面表示も、
すべてその媒体の規定で行います。

出典を画面に出しました。LINEとTikTokとYahoo!ディスプレイは
「要確認」と書いてあります。ここは鈴木さんに直していただきたいです。
辞書に無い媒体は「規定を確認できていない媒体」と表示します。

6 表示速度
PageSpeed Insights の実測に置き換えました。
実ユーザーの計測値（CrUX）、その場の計測値、
短縮見込みのある改善を秒数付きで出します。

**ここだけ設定をお願いしたいです。**
Google Cloud で PageSpeed Insights API を有効にして
キーを発行していただけますか。
いま地図用のキーを流用していて、そのキーでは許可されていません。
設定前でもレポートは止まらず、測れない理由を画面に出します。

7 画像入りバナー
サイトに載っている画像から選べるようにしました。
6サイズすべてで文字あふれが無いことを確認しています。
生成画像は使いません。実際に載っている写真のほうが安全で、
見た人の記憶とも一致すると考えています。

写真と文字は重ねていません。重ねると日本語が読めなくなり、
読ませるために暗幕を敷くと加工した写真に見えるためです。

▼ 触っていて見つけて直したもの

・URLを「example.jp」のようにhttps://無しで入れると分析が失敗していました
・失敗の理由が画面に出ず、英語の定型文しか表示されていませんでした
・表示速度の測定が返らないとき、レポート全体が止まっていました
・「オンライン広告」がLINEの規定として扱われていました
・Yahoo!ディスプレイがGoogleディスプレイの規定として出ていました
```
