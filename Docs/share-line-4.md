# 鈴木さんへのLINE返信（レポート出力後のフィードバック対応）

いただいた順に並べている。検討事項（MCP・PageSpeed）は答えを添える。

---

```
鈴木さん

フィードバックありがとうございます。直したものと、
ご判断いただきたいものを分けてお送りします。

■ 入力タブ

・SNSのステータスを直しました。
　数値が取れたときだけ「分析済み」、ページが開けただけなら「検出」です。
　いまのIBクリニックさんは、LINEもInstagramも「検出」になります。

・LINEは検出のみにしました。友だち数は公開されていないので、
　取りに行くのをやめています。

・SNSのデータ取得について、選択肢を整理しました。

　1 YouTube
　　APIキーだけで登録者数・動画数・再生数が取れます。無料枠内で収まります。
　　PageSpeed と同じ Google Cloud のキーで有効化できるので、
　　追加費用はかかりません。すぐ入れられます。

　2 Instagram / Facebook
　　公開ページはログインを求められて読めません。
　　正規の方法は Meta のAPIで、API自体は無料ですが、
　　クライアントごとにアカウントを連携していただく必要があります。
　　（Instagramをビジネスアカウントにして、Facebookページと紐づける作業）

　3 X（旧Twitter）
　　公式APIが有料です。月200ドルからの枠になります。

　4 外部のスクレイピング代行サービス
　　月額数千円から使えますが、各媒体の規約に反する可能性があり、
　　クライアントのアカウント停止のリスクを負わせることになります。
　　こちらはおすすめしません。

　まず1だけ入れて、2は連携の手間と見合うかご判断いただく、
　という進め方はいかがでしょうか。

■ 施策タブ

・KPI候補から「追えません」を出さないようにしました。
　事業として重要でも追えない指標は候補から外し、
　代わりに「その指標に効く、追える指標」を選ばせています。
　（例：来店数が追えないなら、電話タップ数や予約フォーム到達数）
　「連携が必要です」はこれまでどおり候補に出します。

　これまでのレポートでは、KPI候補24件のうち10件が「追えません」でした。

■ 分析データタブ

・目次を最初から開いた状態にしました。

・LINE広告・Yahoo!ディスプレイ・TikTokの規定、
　いただいた数字をそのまま辞書に入れました。

　　LINE広告　　見出し1件20文字／説明文1件75文字
　　YDA　　　　見出し5件30文字／長い見出し5件90文字／説明文5件90文字
　　TikTok　　 ブランド名1件 全角20文字／広告テキスト1件 全角50文字

　YDAの「長い見出し」は枠自体が無かったので、
　生成・文字数チェック・画面表示に追加しました。
　LINEの説明文はフォーマットにより75〜90文字とのことなので、
　狭いほうの75文字で作らせています。
　出典も「運用者（鈴木）提供・2026-09」に更新しました。

・バナー画像の見切れ対策を入れました。
　「切り抜く」と「全体を入れる」を選べます。
　全体を入れると余白は出ますが、画像内の文字は欠けません。
　切り抜く場合は表示位置を9か所から選べるので、
　文字が入っている側を外して寄せられます。

　自動で文字部分だけを避けて切るには画像解析が要るので、
　いまは操作で確実に避けられる形にしています。
　自動化が必要でしたら、そこは別途ご相談させてください。

■ 表示速度について

こちらはコードとしてはすでに PageSpeed Insights のAPIを叩いています。
止まっているのは権限だけです。

　エラー：Requests to this API pagespeedonline method ... are blocked.

いま地図用のAPIキーを流用しているのですが、
そのキーで PageSpeed Insights API が許可されていません。

Google Cloud で PageSpeed Insights API を有効にして、
キーを発行していただけますか。
発行いただければ、こちらで環境変数に設定して有効になります。
（同じキーで YouTube Data API も有効にしていただければ、
　上の1もそのまま動きます）
```
